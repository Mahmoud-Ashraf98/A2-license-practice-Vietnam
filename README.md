# Đường — Vietnamese motorcycle theory practice

Open the app: https://mahmoud-ashraf98.github.io/A2-license-practice-Vietnam/

Complete static PWA with 250 official A/A1 questions, 20 motorcycle-critical questions, 128 original source figures, reviewed English learning support, strict mocks, offline progress and backups.

## Confidence and mastery

Confidence is optional, with no default Sure. English or phrase assistance is recorded automatically; correct answers with help count as practice and never as Vietnamese mastery. A skipped rating is stored as unrated, not guessed or unsure. Mastery requires repeated correct, explicitly confident Vietnamese-only answers on separate days. Existing saved progress remains compatible.

This branch publishes the app through GitHub Pages, from gh-pages and the root folder.

The current exam profile is valid through 28 February 2027, Vietnam time. English learning content is AI-authored and reviewed, not an official English translation.
